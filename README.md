# 數學闖關樂園

國小六年級數學互動複習網站：最大公因數與最小公倍數。

## 內容
- 五個循序漸進的闖關關卡
- 關卡測驗與即時解題解析
- 星星獎勵與五款徽章
- 錯題本、答題統計與進度紀錄
- 學習紀錄保存在使用者目前裝置的瀏覽器中（localStorage）
